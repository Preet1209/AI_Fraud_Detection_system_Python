# AI Powered Payment Fraud Detection System

## 📌 Project Overview
An AI-based system that detects fraudulent credit card transactions in real time using Machine Learning techniques.

## 🎯 Objectives
- Detect fraudulent payment transactions using AI
- Classify transactions as **Legitimate** or **Fraudulent**
- Analyze transaction patterns and identify anomalies in real time
- Evaluate model using precision, recall, and F1-score

## 🛠️ Tools & Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- Google Colab
- GitHub

## 📊 Dataset
- Source: Kaggle
- File: `creditcard.csv`
- Contains real credit card transactions labeled as fraud or legit

## ⚙️ ML Models Used
- Logistic Regression
- Random Forest

## 📏 Evaluation Metrics
- Precision
- Recall
- F1-Score
